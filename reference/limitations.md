# Known limitations

What does not work yet, in language that is safe to say out loud. This is the document that stops
someone overpromising in a room.

| Area | Status | Note |
|---|---|---|
| Endoscopy modules | Not built | In build. Must be assignable to named people only, never belt-triggered or facility-wide. |
| Scripts as an assignable module | Not built | The 70 scripts exist in the platform. There is no way to assign them to a person yet. |
| Black Belt observation checklist | Empty | Awaiting content. The gate cannot function without it. |
| Manual staff add | Partial | Only offers White Belt. 56 of 92 staff sit at White and 28 of those still need placement, so half the White population is unassessed. |
| Concurrent load | Untested | Nothing has measured what happens when a site onboards 200 people at once. Busiest week on record is 27 distinct users. |
| Observation throughput | Low usage | Three observation records in the platform's history against 12 seeded checklists. Cause not yet established. |
